1. Bubble sort processes slower because it executes more swaps and does over and over again. Selection sort only swaps a couple of times and insertion sort goes from one item to the next.
 
2. Big-O notation only shows how the time grows as the list gets bigger. It ignores
small details, like how many swaps each sort does. 
 
3. The class needs to be comparable, which means Python can tell which of two
objects is smaller. To do this, the class needs comparison methods like
less than and greater than. 

4. It is something more fundamental. Python's built-in sort is a better
algorithm (O(n log n)), and ours are O(n^2). which makes a big difference on big list.
